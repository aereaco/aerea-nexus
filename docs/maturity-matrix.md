# Aerea-Nexus Per-Capability Maturity Matrix

> **Policy:** Maturity labels apply to **individual capabilities**, never entire subsystems, so documentation never claims more than the code and automated tests actually guarantee.

| Capability | Maturity | Verified Guarantees | Known Remaining Limitations |
| :--- | :--- | :--- | :--- |
| **NEXUS-ID-v1 Identity & Key Rotation** | `interoperable` | Self-certifying BLAKE3 IDs, canonical length-prefixed Ed25519 genesis & rotation chains, compromise & replay rejection. | Hardware HSM/YubiKey root-key storage not yet integrated. |
| **OIDC / OAuth 2.1 (PKCE S256, EdDSA JWKS)** | `interoperable` | `GET`/`POST` `/oauth/v2/authorize`, form/Basic/JSON `/oauth/v2/token`, RFC 7519/8037 validator, DB-atomic `jti` replay protection. | Live external third-party OIDC RP/OP interop test suite pending. |
| **WebAuthn / FIDO2 Passkeys** | `interoperable` | W3C registration/authentication ceremonies via `webauthn-rs 0.6.2` (`iam-webauthn`), exact origin & clone-counter checks. | Requires real browser authenticator E2E suite. |
| **Sessions & Cross-Instance Revocation** | `interoperable` | `IdentityWide` vs. `Organization` isolation, persist-before-publish ZCZS cache, DB-transactional `sys_iam_revocation_epoch` with fail-closed session validation. | Multi-node cluster revocation latency benchmarks pending. |
| **SCIM 2.0 Provisioning** | `experimental` | `/scim/v2/Users` & `/scim/v2/Groups` with fail-closed membership/session revocation preserving personal identity. | Sorting, ETags, bulk operations, and DB-indexed pagination pending; multi-record deprovisioning is ordered fail-closed rather than a single cross-table transaction. |
| **SAML 2.0 Federation** | `experimental` | SP metadata XML, ACS endpoint, DB-atomic `Assertion ID` replay protection, time-window validation. | Full standards XMLDSig C14N / RSA-ECDSA verification pending vetted XML-DSig crate integration. |
| **Scoped Mesh Consensus (`CftFastPath`)** | `experimental` | Durable per-voter `VoterNode` vote-locks (`CREATE` insert-if-absent), parallel 1-RTT vote fan-out, `query_slot_lock` coordinator crash recovery, complete canonical membership-transition digests, and two-phase authenticated + DB-atomic `FencedResourceGuard` with O(1) local hot-path checks. Verified across 3 separate OS processes over TCP. | Full leaderless multi-round catch-up / view-change replication and WAN partition benchmarks against a Multi-Paxos/Raft baseline pending. |
| **Scoped Mesh Consensus (`BftSigned`)** | `prototype` | Signed `3f + 1` quorum threshold and cryptographic `EquivocationProof` detection. | Full Byzantine view-change and liveness protocol (HotStuff/Tendermint) not yet implemented. |
| **CRDT Resource Fabric & Scheduler** | `experimental` | Single canonical length-prefixed signing covering all capability fields (`gpu.apis`, `wasm_slots`, `available_ram_mb`, CAS CIDs), membership-authenticated merge, deterministic `(lamport_ts, tombstone, digest)` convergence, ingestion expiry & `gc_expired`, `ReservationLedger`, verified CAS locality. | `ReservationLedger` is currently coordinator-local (distributed reservation authority pending); live multi-host GPU/Wasm workload density benchmarks pending. |
